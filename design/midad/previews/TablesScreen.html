What is different

  • The verb takes over the search field. One bar with two states: search until you choose, then the verb itself — its citation and its meaning. The X is the only way back to searching, so the screen is never ambiguous about which word it is showing.
  • Every form the verb has is on the screen. Which forms exist is a fact about the verb — كَتَبَ has I, II, III, IV, VI, VIII, X and نَصَرَ has five — so it is not something to open a menu to discover. Each chip carries the numeral and the wazn, the same control Practice uses for forms; Form I's wazn shows its bāb (فَعَلَ, فَعِلَ), which differs from root to root. Tapping one puts that form's citation and meaning in the bar above.
  • The table waits for “View the table”. The line above the button names the chart you are about to open, and changing any axis re-arms it — so the table on screen is always the one you asked for, never a half-changed selection.
  • Fourteen rows, one per ṣīgha (PRODUCT_SPEC §5.6), which is how the paper chart a student owns is laid out. The three-column paradigm grid is the peek inside a quiz — a different job, a different component.
  • Gaps are shown as gaps. Ask for the majhūl of an intransitive verb and the row says why instead of offering an empty table.

Worth knowing

  • Re-arming costs a tap when you are comparing two charts of the same verb. The alternative — a table that updates live under the pickers — makes the View button meaningless after its first press. This way the button means one thing every time.
  • Colouring the affixes down a column (the thing that makes a chart teach) needs the engine to return prefix / stem / suffix. That export has to exist before the corpus freeze (ROADMAP B3), like waznRoot.
